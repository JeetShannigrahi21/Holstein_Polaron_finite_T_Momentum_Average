# Fig03_eff_mass_lifetime

## Plotted parameters
MA(1); effective mass m*/m0 and thermal broadening eta* = eta_T - eta_0 (proportional to 1/tau) vs temperature, for the 1D, 2D and 3D Holstein polaron across coupling regimes. t=1, Omega=2t; eta0=0.001 (1D) and 0.01 (2D, 3D). Each row of the figure is one dimension; each curve is one lambda.
Temperature is shown in the paper as `T/Omega` (up to T ~ 0.5 Omega).



## Curves (per dimension)
- **1D**: lambda = 0.2, 0.5, 0.75, 1.125, 1.25, 1.5, 1.75 
- **2D**: lambda = 0.2, 0.5, 0.75, 1.125, 1.25, 1.5, 1.75 
- **3D**: lambda = 0.2, 0.5, 0.75, 1.125, 1.25, 1.75
